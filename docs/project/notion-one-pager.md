## **💡 어떤 동기에서 프로젝트를 시작하게 되었나요? (어떤 문제를 해결하려고 하나요?)**

"그때 내가 그 말만 안 했어도…"라는 후회는 누구에게나 있습니다. 하지만 카톡 기록은 수만 줄이라 직접 읽기엔 너무 길고, 감정적으로 다시 훑기도 힘듭니다. 기존 도구는 요약이나 감정 분석에 그치고, **특정 순간을 바꿨을 때 관계가 어떻게 달라졌을지**까지 보여주지는 않습니다.

**What if…?**는 카톡 내보내기 한 번으로
1) 대화 밀도·답장 지연 등 **위험 구간**을 찾고,
2) AI가 **헤어진/어긋난 이유**를 근거와 함께 정리하며,
3) 그 순간 **다른 말을 했다면** 어떤 흐름이 펼쳐졌을지 **반사실 시뮬레이션**까지 보여줍니다.

---

## **👥 누구를 위한 서비스인가요?**

- 연애·친구·팀 관계에서 **대화 패턴을 객관적으로 돌아보고 싶은 사람**
- 긴 카톡 기록을 **빠르게 분석**하고 싶지만, **서버에 대화를 올리고 싶지 않은 사람**
- 해커톤·데모 관객처럼 **"평행우주 카톡"** 컨셉에 바로 공감하는 사용자

1:1 관계 분석(리포트·반사실)과 단톡방(페르소나·시뮬) 모두 지원합니다.

## **✨ 기존 방식보다 어떤 점이 나아지나요?**

| 기존 | What if…? |
| --- | --- |
| 카톡을 처음부터 끝까지 직접 스크롤 | 로컬 통계로 **밀도 급락·답장 지연** 구간 자동 표시 |
| "왜 헤어졌지?" 감으로 추측 | LLM이 **근거 인용**과 함께 관계 리포트 생성 |
| 후회는 머릿속 상상에 그침 | **"여기서 이렇게 말했더라면"** → 대체 카톡 타임라인 시뮬 |
| 클라우드 업로드 불안 | **원문은 브라우저(IndexedDB)에만** 저장, 서버는 LLM 프록시만 |
| OpenRouter만 가능 | **OpenRouter** + **코딩 에이전트(JSON import)** 이중 분석 경로 |

## **🎯 반드시 구현할 핵심 기능은?**

1. **카톡 업로드 & 파싱** — macOS CSV / Android·iOS·PC txt 4종 자동 감지
2. **로컬 통계 (LLM 0회)** — 답장 지연, 대화 밀도, 세션 위험 점수, 타임라인 마커
3. **LLM 분석 (map-reduce)** — 구간별 분석 → 전체 종합 (1:1 / 그룹)
4. **결과 3종** — 헤어진·어긋난 이유 / 위험 구간 / 내 실수 + 더 나은 버전
5. **반사실 시뮬** — 특정 순간 선택 → 대체 대사 + 갈라진 카톡 흐름
6. **IndexedDB 저장** — 재방문 시 분석 결과 복원

## **🧗 이 프로젝트를 하면서 부딪쳤던 도전과제들**

1. **카톡 export 지옥** — macOS는 txt가 아니라 **CSV(BOM)**; Android는 U+202F 구분자 등 **4종 포맷** 실측 대응
2. **수만 줄 대화** — 통컨텍스트 불가 → **로컬 선분석 + 구간 map-reduce** 설계
3. **프라이버시 vs LLM** — 원문 서버 저장 금지, **청크만 프록시 전송** + UI에 명시
4. **이중 분석 경로** — OpenRouter 장애·키 없음 대비 **코딩 에이전트 JSON import** 폴백
5. **실데이터 Git 유출 방지** — `data/chat-exports/` gitignore, fictional public demo 분리
6. **3시간 해커톤 타임박스** — P0만 PRD에 못 박고, UX polish는 우선순위 큐로 관리

## **🏆 가장 자랑스러운 부분**

- **프라이버시가 기능** — No DB, IndexedDB only. "대화는 당신 브라우저에만"을 제품 카피가 아니라 아키텍처로 구현
- **실제 카톡 파일로 검증된 파서** — 추측이 아닌 실측 export 3종 골든 테스트
- **Money shot 완성** — 업로드 → 타임라인 빨간 마커 → "여기서 이렇게 말했더라면" → **평행우주 카톡**
- **프로덕션까지** — [whatif.raehyeon.com](https://whatif.raehyeon.com/) 에서 바로 체험 가능

## **📝 배운 점**

- **문서 먼저, 코드 나중** — PRD를 정본으로 두면 AI 에이전트 병렬 작업 시 드리프트가 줄어듦
- **로컬 선분석의 가치** — LLM 호출 전 통계로 구간을 좁히면 비용·품질·속도 모두 개선
- **프라이버시는 설계 문제** — "안 올린다"고 말하는 것보다 **저장하지 않는 구조**가 신뢰를 만듦
- **에이전트는 API 대체재** — OpenRouter 없이도 Cursor/Codex로 분석 JSON을 만들어 import하면 데모가 살아남
- **발표는 한 흐름** — 기능 나열이 아니라 **후회 → 발견 → 평행우주** 한 줄 스토리가 중요
