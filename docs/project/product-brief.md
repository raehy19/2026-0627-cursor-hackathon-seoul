# 제품 브리프 — What if…?

## 한 줄 설명
- 카톡 대화 내보내기 파일을 넣으면, **어디서 어긋났는지** 찾아내고 **"그때 이렇게 말했더라면"** 평행우주를 실제 카톡 버블로 시뮬레이션해주는 웹 서비스.

## 현재 상태
- 제품 문제 정의: 확정 (관계/대화 회고 + 반사실 시뮬레이션)
- 대상 사용자: 지난 관계·대화를 곱씹어본 사람 (전 연인 1:1 / 친구 단톡방)
- 핵심 사용 시나리오: 확정 (아래 데모 흐름)
- 플랫폼 범위: 웹 SPA (Next.js) 단독, 모바일 대응은 후순위
- 수익화: 없음 (해커톤 데모)

## 핵심 제약 (못 박음)
- **No DB.** 모든 사용자 데이터는 브라우저 IndexedDB에만 저장. 서버는 OpenRouter 호출 프록시(`/api/llm`) 역할만.
- **프라이버시가 곧 기능.** 원문 카톡은 서버에 저장하지 않음. LLM 호출 시 필요한 청크/샘플만 일시 전송.
- **무료 스택.** LLM은 OpenRouter 무료 모델(휘발성 대비 폴백 리스트). 키는 얇은 백엔드 프록시에만 보관.
- **거대 입력 대응.** 수만 줄(실측 23MB·38만 줄) → 로컬 통계로 볼 구간을 좁히고 구간 분할 map-reduce.

## 두 가지 모드 (참가자 수로 자동 분기)
- **1:1 (회고형):** 헤어진 이유(근거 인용) · 위험했던 구간 · 내 실수(+더 나은 버전) · "그때 이렇게 말했더라면" 반사실(현실/해피/망함).
- **그룹 (예측형):** 참가자별 페르소나 학습 → "내가 이걸 올리면 누가 어떤 순서로 어떻게 받아칠까" 단톡방 시뮬레이션(톤/모드/시간대 노브).

## 데모 흐름 (the money shot)
1. 카톡 `.txt`/`.csv` 업로드 → 자동 파싱(포맷 4종 감지)
2. 타임라인 그래프에 대화 밀도/답장 지연 + 위험 구간 빨간 마커
3. (1:1) "헤어진 이유" 카드(근거 인용) → 마커 클릭 → "여기서 이렇게 말했더라면" → 대체 카톡 흐름 생성
4. (그룹) 멤버별 페르소나 카드 → 가상 메시지 입력 → 각자 말투 그대로 카톡 스레드가 좌르륵

## 기술 스택
- Next.js(App Router) + Tailwind v4 + papaparse(CSV) + idb-keyval(IndexedDB) + Recharts(타임라인)
- `/api/llm` 프록시 → OpenRouter (OpenAI 호환, 무료 모델 폴백)
- 배포 대상: Vercel (루트 디렉토리 `web`)

## 실측 검증 (골든 샘플 3종, repo 루트)
- macOS CSV(`공돌이들`, 그룹 5인, 4,414 레코드) · 안드로이드 영문 txt(같은 방, 38만 줄·5.7년) · 안드로이드 영문 1:1 txt(전 연인 `서연이`)
- 확인된 지뢰: CSV BOM, U+202F(시각↔AM/PM), `wc -l` ≠ 레코드 수, N명 단톡(2명 가정 폐기)

## 범위 밖 (MVP 제외)
- 회원가입/로그인/결제, 서버 영속화, 다국어 UI, 모바일 네이티브, 읽음(1) 추정 단정

## 성공 기준
- 실측 파일 3종이 깨지지 않고 파싱된다.
- 로컬 통계 대시보드/타임라인이 LLM 없이도 동작한다.
- 1:1 반사실 또는 그룹 시뮬 중 최소 하나가 카톡 버블로 끝까지 시연된다.
- 재방문 시 IndexedDB에서 이전 분석이 복원된다.
